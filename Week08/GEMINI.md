# Project: OpenAPI FastAPI Server

## Project Overview

This project is a Python web service built with the FastAPI framework. The API is defined by an OpenAPI 3.1 specification (`openapi.yaml`) and the server code was initially generated by the OpenAPI Generator.

The primary purpose of this application is to provide a CRUD (Create, Read, Update, Delete) API for managing products. It also features a JWT-based authentication system with endpoints for logging in (`/auth/login`) and refreshing tokens (`/auth/refresh`).

The application uses MongoDB as its database, as indicated by the `motor` driver in the `requirements.txt` file.

## Building and Running

There are two primary ways to run the application: locally using a Python environment or via Docker.

### Local Development

1.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

2.  **Run the Server:**
    ```bash
    PYTHONPATH=src uvicorn openapi_server.main:app --host 0.0.0.0 --port 8080
    ```

Once running, the API documentation will be available at `http://localhost:8080/docs`.

### Docker

To build and run the application as a Docker container, use Docker Compose:

```bash
docker compose up --build
```

This will start the service and expose it on port 8080 on the host machine.

## Development Conventions

### Code Style

*   **Formatting:** The project uses `black` for consistent code formatting.
*   **Import Sorting:** Imports are sorted using `isort` with the "black" profile.

Configuration for these tools can be found in `pyproject.toml`.

### Testing

*   **Framework:** Tests are written using the `pytest` framework.
*   **Location:** Test files are located in the `tests/` directory.
*   **Running Tests:** To execute the test suite, run the following command from the project root:
    ```bash
    PYTHONPATH=src pytest tests
    ```
*   **Note:** The existing tests appear to be generated boilerplate. They will need to be implemented to provide meaningful test coverage.
